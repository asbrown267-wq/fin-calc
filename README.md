# Finance Manager

A simple, secure personal finance calculator to manage monthly budgets.

## Features
- Track monthly payments across Halifax, Monzo, and daughter's savings
- Calculate remaining balances for current and next month
- See exactly how much is safe to save without bouncing direct debits
- Track debts and overall financial position

## How to Use
1. Download `finance-manager.html`
2. Open it in any web browser (Chrome, Firefox, Safari, Edge)
3. All your data stays private in your browser - nothing is sent to any server

## Privacy
- 100% offline - works without internet
- All data stored locally in your browser only
- No data is uploaded to GitHub or anywhere else
